# Welesza — plansze referencyjne materiałów przyrodniczych

Cztery autorskie plansze z przykładami użycia faktur w środowisku gry:

1. [Podłoże, błoto i leśny trakt](01_materialy_podloza_bloto_trakt.png)
2. [Roślinność: trawa, mech, runo](02_roslinnosc_trawa_mech.png)
3. [Drewno, kora, korzenie](03_drewno_kora_korzenie.png)
4. [Kamienie, skały, porosty](04_kamienie_skaly_porosty.png)

**Ważne:** plansze są materiałem koncepcyjnym i nie są przeznaczone do bezpośredniego nakładania na modele w Blenderze.

Do właściwych map koloru przejdź do [biblioteki PNG](../../../../assets/textures/environment/README.md). Wersje repozytoryjne plansz mają natywną rozdzielczość 1254 × 1254, paletę 256 kolorów dla lżejszego repozytorium.
